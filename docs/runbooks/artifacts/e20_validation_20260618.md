## Method

The original `scripts/0252/compare_e20.py` was never committed and is lost;
this is a committed, self-contained reimplementation that queries **ClickHouse
directly** (`docker exec app-clickhouse-1`) instead of the API endpoint — so it
needs no API redeploy and no `api_reader` quota.

Per anchor pool it compares the transaction hash-set CH attributes
(`has(pool_ids, X)`) to Horizon's `/liquidity_pools/{id}/transactions`, over the
ledger window Horizon still retains, capped at `W = max(sequence)` (CH is frozen
at the last-ingested ledger; Horizon runs live ahead). It reports:

- **recall** = |Horizon ∩ CH| / |Horizon| — did the backfill MISS real pool txs?
- **precision** = |Horizon ∩ CH| / |CH| — did it OVER-ATTRIBUTE non-pool txs?

Anchors: top-200 pools by pool-touching op count (`type IN (2,13,22,23)`).
Live-drift is handled by a constructed TOID cursor `(W+1)<<32` + `order=desc`
that jumps Horizon straight to the `≤ W` window (the hottest pools have
thousands of post-W drift txs — paging back is infeasible).

Two systematic patterns, confirmed by CH-side op-type inspection:

- **recall −4 tx** — all `change_trust` (op type **6**) to the pool's _share_
  asset (trustline establish/remove). Horizon lists these in
  `/liquidity_pools/{id}/transactions`; CH does **not** attribute `change_trust`
  to a pool — the 0266 backfill only extracts `pool_ids` from op types
  2/13/22/23. A scope difference, not a miss.
- **precision +3 tx** — all `liquidity_pool_deposit` (op type **22**, `pool_ids`
  correctly = the anchor pool) inside **failed transactions**
  (`transactions.successful = false`). CH indexes ops from failed txs; Horizon's
  pool-tx list is successful-only. CH ⊇ Horizon here — a `successful-only`
  difference (cf. the documented `op_count successful-only` tolerance).

Both are pre-existing CH↔Horizon semantic differences (see
`feedback_ch_horizon_semantic_diffs`), independent of the path-payment fix
arc. The 0261/0266/0268 work — single- and multi-hop path-payment pool
attribution — is confirmed correct on all 200 anchors.
